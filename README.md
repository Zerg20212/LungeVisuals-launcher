# LungeVisuals

**Свой интерфейс, визуальные эффекты и удобное управление Minecraft Java Edition.**

LungeVisuals объединяет мод для Fabric и лаунчер для Windows. Настраивай внешний вид игры, собирай собственный HUD и управляй сборками из одного приложения.

## Установка

1. Открой страницу последнего релиза и скачай `LungeVisuals-Setup.exe`.
2. Выбери папку установки. Для установки в папку пользователя права администратора не нужны.
3. Запусти лаунчер, выбери вход через Microsoft во внешнем браузере или локальный профиль по нику.
4. Во вкладке версий создай экземпляр LungeVisuals и выбери Minecraft.
5. Нажми «Играть». Лаунчер подготовит Java, Minecraft, Fabric и необходимые файлы.

Для запуска без установщика скачай архив `portable.zip` из релиза и распакуй целиком в отдельную папку. Не запускай программу прямо из архива.

Microsoft-профиль использует лицензию Minecraft Java Edition. Локальный профиль предназначен для одиночной игры и серверов, которые допускают такой вход.

## Лаунчер

- Создание и переименование отдельных экземпляров игры.
- Установка сборок из Modrinth и переход в каталог CurseForge.
- Выбор версии Minecraft и настройка выделяемой оперативной памяти.
- Автоматическая загрузка компонентов игры и Fabric.
- Вход Microsoft через обычный браузер.
- Уведомления о новых версиях и обновление через GitHub Releases.
- Собственные иллюстрации и оформление LungeVisuals.

## Интерфейс и HUD

Выбирай стиль оформления, основной цвет и расположение панелей. Стиль применяется также к инвентарю.

В HUD доступны информация об игре и FPS, координаты, скорость, эффекты зелий, перезарядки, нажатия клавиш, активные бинды, боссы, инвентарь и хотбар. Здоровье, голод и опыт можно отображать числами и полосами. Заменяющие виджеты скрывают соответствующие стандартные элементы Minecraft.

Открой чат, чтобы перемещать виджеты. ПКМ открывает настройки; кнопки добавления и удаления позволяют вернуть или скрыть панели. Настройки отдельной функции открываются по ПКМ на её карточке в меню. Менеджер биндов позволяет назначать клавиши и команды.

## Визуальные функции

Эффекты персонажа: China Hat, нимб, круги прыжка, следы движения, эффекты попадания и частицы. Настройки прицела, руки и предметов, подсветки блока, хитбоксов и линий направления. Яркость, оформление неба и атмосферы, масштабирование камеры, соотношение сторон, анимации интерфейса и отключение отдельных эффектов.

## Удобство игры

Свободный обзор и Freecam, защита слотов от случайного выбрасывания, перемещение и замена предметов, настройки еды, уведомления о подборе предметов, управление звуками и режим стримера. Поиск помогает быстро найти функцию; конфигурации сохраняют наборы настроек.

Plasmo Voice и Wall Jump входят в комплект. Их параметры доступны из интерфейса LungeVisuals. Для голосового общения сервер также должен поддерживать Plasmo Voice. Возможности перемещения и взаимодействия зависят от правил и настроек сервера.

## Доступ к функциям

Без ключа доступны Plasmo Voice и Wall Jump. Для остальных функций введи ключ в профиле мода. Профиль показывает состояние доступа и срок его действия. Ключ LungeVisuals не заменяет лицензию Minecraft.

## Minecraft 26.3

Для 26.3 используется Fabric Loader 0.20.1 и Java 25. Яндекс Музыка открывается во внешнем браузере: отдельная загрузка Chromium для этого экземпляра не нужна. Более ранние комплекты доступны в соответствующих релизах и списке версий лаунчера.

## Обновления и данные

Лаунчер предлагает обновление при появлении нового релиза. Проверить обновления вручную можно в настройках. Перед установкой обновления закрой игру и лаунчер; укажи папку существующей установки. Миры и настройки экземпляров сохраняются отдельно от обновляемых файлов программы.

Не передавай другим людям папки аккаунтов, токены и личные ключи. Для скачивания публичного релиза GitHub-токен не нужен.
